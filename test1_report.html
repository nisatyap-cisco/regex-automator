Policies (10)
  • IFSC code must be exactly 11 characters long (Source: GeeksforGeeks, multiple banking sources)
  • First four characters must be uppercase alphabetic letters representing the bank code (e.g., SBIN for State Bank of India, HDFC for HDFC Bank, ICIC for ICICI Bank)
  • Fifth character must always be '0' (zero), reserved as a separator for future use
  • Last six characters (positions 6-11) represent the unique branch code and are alphanumeric (can be numeric or alphabetic, typically numeric)
  • The format follows the regular expression pattern: ^[A-Z]{4}0[A-Z0-9]{6}$ (Source: GeeksforGeeks validation examples)
  • Each bank branch in India has a unique IFSC code - no two branches share the same code
  • IFSC codes are used exclusively for domestic electronic fund transfers within India via NEFT, RTGS, and IMPS systems
  • Currently approximately 130,000 IFSC codes have been assigned by RBI to various banks and branches across India
  • All characters must be in uppercase format - lowercase letters are not valid
  • The code structure is: Bank Code (4 chars) + '0' (1 char) + Branch Code (6 chars) = 11 total characters

Policies (14)
  • IPv6 addresses are 128 bits in length (RFC 2460, Section 3)
  • IPv6 addresses are written as eight groups of four hexadecimal digits separated by colons (RFC 2460, industry standard notation)
  • Each group represents 16 bits, using hexadecimal digits 0-9 and A-F (RFC 2460, Section 3)
  • Leading zeros in each group may be omitted (e.g., 0db8 becomes db8, 0042 becomes 42)
  • One sequence of consecutive all-zero groups may be replaced with double colon (::), but this compression can only be used once per address
  • When replacing consecutive zero groups with ::, the longest run of consecutive all-zero groups should be replaced
  • The IPv6 header contains a 4-bit version field with value 6 (RFC 2460, Section 3)
  • Source and Destination Address fields are each 128 bits (RFC 2460, Section 3)
  • IPv6 addresses in URLs must be enclosed in square brackets (e.g., http://[2001:db8::1]:8080)
  • Prefix length notation uses slash notation similar to IPv4 CIDR (e.g., 2001:db8::/32, fe80::/10)
  • The loopback address is ::1 (full form: 0000:0000:0000:0000:0000:0000:0000:0001)
  • The unspecified address is :: (all zeros)
  • Link-local addresses use the fe80::/10 prefix
  • Extension headers must be integer multiples of 8 octets in length (RFC 2460, Section 4)
